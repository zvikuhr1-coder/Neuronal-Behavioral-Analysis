# Module 02: Behavioral Tracking Synchronization

## Overview
This module synchronizes DeepLabCut behavioral tracking with calcium imaging acquisition. It processes video timestamps, filters arena boundaries, corrects tracking artifacts, and produces frame-aligned datasets suitable for integrated behavior-neural analysis.

## Key Features
* **Arena Boundary Filtering:** Programmatically filters tracking coordinates outside experimentally defined arena polygon to remove detection artifacts.
* **Temporal Alignment:** Maps 10Hz imaging frames to ~20Hz video frames with <20ms precision using FFmpeg-extracted timestamps.
* **LED-Based Trial Detection:** Automatically identifies trial start frames via change point analysis of LED indicator intensity.
* **Outlier Correction:** Removes tracking artifacts using 15-frame moving window interpolation with 15-pixel deviation threshold.
* **Multi-Trial Concatenation:** Combines all trials into continuous synchronized dataset with consistent frame alignment.

## DeepLabCut Integration
This pipeline requires a **CSV file** generated by DeepLabCut (DLC), an external pose estimation tool. DLC must be run **before** this pipeline to produce frame-by-frame tracking coordinates.

**DLC Workflow (External):**
1. Label body parts on sample video frames
2. Train neural network for pose estimation
3. Run inference on behavioral videos → generates CSV output
4. Run this pipeline to synchronize CSV with imaging data

**Expected CSV Format:**
```csv
scorer,DLC_model,DLC_model,DLC_model,...
bodyparts,nose,nose,left_ear,left_ear,...
coords,x,y,likelihood,x,y,likelihood,...
0,245.3,189.2,0.98,248.1,192.5,0.95,...
1,246.1,190.3,0.97,249.0,193.2,0.96,...
```

The pipeline extracts X/Y coordinates from multiple body parts and computes the median for robust tracking.

**DLC Resources:** https://deeplabcut.github.io/

## Pipeline Stages

### Stage 1: Extract Background Frame
**Function:** `extract_background_frame(data_path)`

Samples 150 random frames from video and computes pixel-wise average for arena visualization.

**Output:**
- `background_frame.mat` - Average background image (uint8 RGB)
- `video_dimensions.mat` - Video height and width (pixels)

### Stage 3: Extract Video Timestamps
**Functions:** `execute_ffmpeg_batch(data_path)`, `parse_video_timestamps(data_path)`

Executes FFmpeg batch file (included in `functions/` folder) to extract frame presentation timestamps from video metadata. Parses output into MATLAB array for temporal alignment.

**Output:**
- `processed/video_timestamps.mat` - Nx1 array of frame times (seconds)

**FFmpeg Command:**
```batch
ffprobe -select_streams v:0 -show_entries frame=pts_time -of csv=p=0 video.avi > timestamps.txt
```

---

### Stage 4: Detect Trial Onsets
**Function:** `detect_trial_onsets(data_path)`

Identifies trial start frames via LED indicator change point detection. First trial detected automatically using linear change point analysis (threshold=500), subsequent trials calculated at 300s intervals. User verifies each trial with ±20s visualization window.

**Output:**
- `processed/trial_starts.mat` - Nx1 array of trial start frame indices

### Stage 5: Synchronize Tracking and Imaging
**Function:** `synchronize_tracking_imaging(data_path)`

Aligns DLC tracking coordinates with calcium imaging frames through temporal mapping, arena filtering, interpolation, and outlier correction. Processes each trial independently then concatenates into continuous dataset.

**Processing Steps:**
1. Load DLC CSV, extract median X/Y from multiple body parts
2. Filter points outside arena polygon (→ NaN)
3. Map 10Hz imaging frames to nearest ~20Hz video frames
4. Flag frames with >20ms temporal mismatch for interpolation
5. Interpolate NaN gaps linearly
6. Correct outliers using 15-frame moving window
7. Concatenate all trials

**Output:**
- `processed/synchronized_tracking.mat` - `x_position_aligned`, `y_position_aligned` (1×N arrays)
- `processed/imaging_data_aligned.mat` - Concatenated imaging data (M×N matrix)
- `processed/frame_alignment_indices.mat` - Imaging frame → video frame mapping
- `processed/interpolation_markers.mat` - NaN markers for poorly aligned frames

## Data Structure

### Input Requirements
```
data_path/
├── video.avi                    # Behavioral video recording
├── DLC_tracking.csv             # DeepLabCut output (external)
├── trial1.dcimg                 # Imaging trial 1
├── trial2.dcimg                 # Imaging trial 2
└── processed/                   # Created by neuronal pipeline
    ├── trial_1_corrected.mat    # Imaging data trial 1
    └── trial_2_corrected.mat    # Imaging data trial 2
```

### Output Structure
```
data_path/
├── background_frame.mat         # Stage 1
├── video_dimensions.mat         # Stage 1
├── arena_polygon.mat            # Stage 2
└── processed/
    ├── video_timestamps.mat                # Stage 3
    ├── trial_starts.mat                    # Stage 4
    ├── synchronized_tracking.mat           # Stage 5
    ├── imaging_data_aligned.mat            # Stage 5
    ├── frame_alignment_indices.mat         # Stage 5
    └── interpolation_markers.mat           # Stage 5
```

**Data Format:**
- Tracking: `1 × N` arrays where N = total imaging frames across all trials
- Imaging: `M × N` matrix where M = ROIs, N = frames
- Coordinates: Pixel values from video (NaN for filtered/missing points)

## Usage

```matlab
% Set data path
data_path = 'C:\Path\To\Your\Data\Folder';

% Add functions to MATLAB path
addpath(fullfile(pwd, 'functions'));

% Run complete pipeline
Behavioral_Tracking_Pipeline
```

**The pipeline will:**
1. Extract background frame (automatic)
2. Define arena boundary (interactive - draw polygon, double-click to finish)
3. Extract timestamps via FFmpeg (automatic)
4. Detect trial starts (interactive - draw LED ROI, verify trials)
5. Synchronize tracking with imaging (automatic)

## Quality Control

**Console Output Metrics:**
```
=== ARENA FILTERING ===
Outside arena: 127 (1.1% of valid points)

=== TEMPORAL ALIGNMENT ===
Frames with >20ms mismatch: 15 (2.5%)

Outliers detected: 48 (0.8%)
```

**Warning Thresholds:**
- Arena filtering >20% → Redraw polygon more inclusively
- Poor alignment >10% → Check video frame rate consistency
- Outliers >5% → Review DLC tracking quality
